# FIGMA PROMPT — AI STUDY COMPANION

## Complete Product Design + Learning Intelligence Experience

Design a complete production-quality web application called **“Study Companion”**.

This is NOT a generic LMS, course platform, or ChatGPT wrapper.

It is an **AI-powered personal learning system** where a B.Tech student uploads their own study material, the system converts that material into a structured knowledge map, teaches the student using grounded AI, tests them, measures actual mastery, detects confidence/correctness mismatches, creates flashcards, analyzes growth, and continuously recommends what they should study next.

The product should feel like:

**“A personal AI learning operating system.”**

The core philosophy is:

> **Upload → Understand → Learn → Practice → Explain → Measure → Detect Weakness → Recommend → Improve**

The interface must make this learning loop visually obvious.

---

# 1. PRODUCT EXPERIENCE

The student should always understand:

1. What am I studying?
2. What concepts exist in my material?
3. What do I actually know?
4. What do I only THINK I know?
5. What should I study next?
6. Why was this recommended?
7. What evidence supports my progress?
8. How has my understanding changed over time?

Do NOT make the application feel like a points/badges/gamification product.

Avoid:

* childish illustrations
* cartoon mascots
* excessive gradients
* meaningless XP
* leaderboards
* fake progress
* generic AI chat UI
* fake analytics
* fabricated trends

Make it feel intelligent, calm, trustworthy and academic.

---

# 2. VISUAL DIRECTION

Create a premium modern educational/productivity interface.

Design language:

* Light mode first
* Dark mode variant
* Clean white/slate surfaces
* One primary indigo/blue accent
* Green = Mastered / Correct
* Amber = Developing / Needs Attention / Mismatch
* Red = Weak / Incorrect
* Gray = Not Yet Assessed
* Restrained shadows
* 8–12px radius system
* Thin borders
* Generous whitespace
* Dense enough for serious studying but never cluttered

Typography:

* Inter or equivalent modern sans-serif
* Strong hierarchy
* Excellent readability for long study content

Use Lucide-style icons.
